# Pancheng Niu · Personal Website

Minimal academic personal website built with static HTML and CSS, deployed through GitHub Pages.

## Structure

- `index.html` — Homepage
- `now.html` — Current research
- `projects.html` — Publications
- `notes.html` — Notes index
- `experience.html` — Education
- `assets/` — Image assets
- `notes/` — Obsidian Markdown notes

## Notes

Write Markdown files in `notes/`. Run `sync-notes.command` to generate the Notes pages and push updates to GitHub.

## Deployment

The site is available at [panchengn.github.io](https://panchengn.github.io/). GitHub Pages publishes the repository from its main branch.
