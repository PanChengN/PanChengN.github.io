# Notes folder

Use this folder as an Obsidian vault or as the notes directory inside your existing vault.

Each note can use this format:

```markdown
---
title: A note title
date: 2026.09.01
summary: A short sentence shown on the Notes index.
---

## Heading

Write your note here in Markdown.
```

After writing, double-click `sync-notes.command` in the project folder. It generates the Notes index and individual note pages, then pushes them to GitHub.
